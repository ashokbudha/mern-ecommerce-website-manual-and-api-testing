# 4xcollection — QA & Test Automation

QA testing and automation project for **4xcollection**, a MERN-stack clothing e-commerce application.

## 🔗 Application

**Live Application:** https://4xcollection.vercel.app/

**Source Code:** Private repository

---

## 📌 Project Overview

4xcollection is a clothing e-commerce web application with **Customer** and **Admin** roles.

The application includes product browsing, search, category filtering, product details, authentication, wishlist functionality, and product management.

This repository documents the complete QA process for the application, from manual testing and API validation to automated end-to-end testing.

## 📋 QA Activities

### Manual Testing

* Analyze application requirements and features
* Design test scenarios and test cases
* Execute functional and negative test cases
* Report and track defects
* Perform regression testing

### API Testing

* Validate REST API endpoints
* Verify status codes and response data
* Test positive and negative scenarios
* Validate authentication and authorization
* Maintain Postman collections

### Database Testing

* Validate application data in MongoDB
* Verify data creation and updates
* Check data consistency between API and database
* Validate important business data

### Test Automation

* Automate critical user workflows using Playwright
* Use TypeScript and Page Object Model
* Build reusable test components
* Generate automated test reports

### CI/CD

* Execute automated tests through GitHub Actions
* Run regression tests automatically
* Publish test results
